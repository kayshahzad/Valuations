4. **Ratio-derivation fallback chains** — silent substitution of 12% ROIC default (MultipleDecomposition), 3% revenue fallback for D&A (DCFEngine), zero-FCF on missing (all downstream). **Gap**: no documented rationale for defaults. **Fix priority**: Phase 1 assumption audit.
5. **CapEx sign convention** — FMP reports negative (outflow); schema expects positive (magnitude). abs() applied at multiple layers (ttm_derivation, cleaning_engine) but inconsistently documented (A6 pattern partly fixed). **Gap**: pre-fix stale TTM rows still have negative CapEx in DB. **Fix priority**: Phase 1 data remediation + persistent schema assertion.
